# Project decisions

Only significant decisions are kept here: architecture, tools, structure, risk, trade-offs or policy changes. Template — `DECISION_TEMPLATE.md`.

## File names

```text
0001-short-title.md
0002-next-decision.md
```

A number is never reused. A changed decision is not deleted: a new one is created, and the old one gets the status `Superseded` with a link to the new one.
