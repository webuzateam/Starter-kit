# Решения проекта

Здесь хранятся только существенные решения: архитектура, инструменты, структура, риск, компромисс или изменение политики.

## Имена файлов

```text
0001-краткое-название.md
0002-следующее-решение.md
```

Номер не переиспользуется. Изменённое решение не удаляется: создаётся новое, а старое получает статус `Заменено` со ссылкой.

## Индекс

Заполняется при создании решений.
