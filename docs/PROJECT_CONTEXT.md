# Контекст проекта

Статус документа: **ОЖИДАЕТ ЗАПОЛНЕНИЯ ЧЕРЕЗ START**

Этот файл заполняется данными выбранного режима START. Агент не должен выдумывать факты о новом проекте и не должен выдавать вывод из файлов за подтверждённый пользователем ответ.

## Происхождение данных

Для значимых неподтверждённых сведений рядом указывается одна пометка:

- `ВЫВЕДЕНО ИЗ ПРОЕКТА` с коротким основанием;
- `ПРИНЯТО ПО УМОЛЧАНИЮ`;
- `ОТЛОЖЕНО`;
- `ТРЕБУЕТ ПОДТВЕРЖДЕНИЯ ПЕРЕД ДЕЙСТВИЕМ`.

Подтверждённые пользователем сведения можно записывать без повторения пометки в каждом предложении, если их источник однозначен в сводке инициализации. Отложенный вопрос не заполняется догадкой.

## Критерии завершения задачи

По умолчанию задача считается завершённой, когда:

- выполнен запрос пользователя;
- изменения находятся в согласованных границах;
- релевантные проверки выполнены или пропущены с объяснением;
- риски и незавершённые части названы;
- отложенные решения не скрыты, а связанные с ними действия заблокированы до нужного подтверждения;
- при закрытии сессии обновлены статус и Git;
- понятен следующий шаг.
