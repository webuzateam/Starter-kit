## Критерии завершения задачи

По умолчанию задача считается завершённой, когда:

- выполнен запрос пользователя;
- изменения находятся в согласованных границах;
- релевантные проверки выполнены или пропущены с объяснением;
- риски и незавершённые части названы;
- при закрытии сессии обновлены статус и Git;
- понятен следующий шаг.
