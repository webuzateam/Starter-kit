# История значимых изменений

Этот файл отражает изменения, заметные пользователю. Он не дублирует список файлов из Git и технические подробности session logs.

## Не выпущено

### Добавлено

- Явная маркировка протокола `START v2` и аудит отсутствия альтернативных списков режимов.
- Три режима первого запуска: тест с сопровождением, быстрый режим и адаптивная настройка без брифа.
- Объяснения, варианты ответов, рекомендации и возможность отложить любой неизвестный вопрос брифа.
- Источники данных, уровни готовности и контрольные точки, которые блокируют только связанное рискованное действие.
- Обязательная замена README мастер-шаблона на README конкретного проекта до первого commit и push.
- Быстрый режим `START` с принятием рекомендуемых значений без пропуска обязательных проверок.
- Реестр `docs/INTEGRATIONS.md` для переносимости Skills, плагинов и MCP без хранения секретов.
- Явное разделение чистого мастер-шаблона и заполненного пользовательского проекта.
- Полная пользовательская инструкция на отдельной странице сайта.

- Базовая структура AI Project Starter Kit.
- Управляемый первый запуск через `START`.
- Настройка по 13 блокам, применение правил и отчёт инициализации.
- Политика приватного GitHub и сохранения всех значимых данных проекта.
- Безопасная обработка секретов и крупных файлов.
- Автоматическое закрытие сессии по отдельной команде.
- Отдельная интерактивная презентация-лендинг, не входящая в репозиторий starter kit.
- Нейтральное название без языкового суффикса и правила будущей локализации.
