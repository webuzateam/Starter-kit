# Действующие правила проекта

Статус политики: **ОЖИДАЕТ ПРИМЕНЕНИЯ ЧЕРЕЗ START**

Этот документ формируется после итоговой сводки выбранного режима START. Каждое правило получает статус `ПРИНЯТО`, `ИЗМЕНЕНО ПОЛЬЗОВАТЕЛЕМ`, `НЕ ПРИМЕНЯЕТСЯ`, `ОТЛОЖЕНО`, `ТРЕБУЕТ ПОДТВЕРЖДЕНИЯ ПЕРЕД ДЕЙСТВИЕМ` или `ТРЕБУЕТ РЕШЕНИЯ`. Рядом указывается источник: пользователь, файлы проекта или безопасное значение Starter Kit.

Отложенный вопрос не блокирует всю работу автоматически. Он блокирует только указанное действие. Неизвестное разрешение на публикацию, deploy, внешнюю отправку, удаление, смену remote, переписывание истории или другую рискованную операцию всегда трактуется как запрет до явного подтверждения пользователя.

## Проектные исключения и изменения

Заполняются при `START`. Каждое изменение должно содержать причину и последствия. Для отложенного решения укажите разрешённую работу, заблокированное действие и событие повторного запроса.
