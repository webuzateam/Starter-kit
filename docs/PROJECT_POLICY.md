# Действующие правила проекта

Статус политики: **ОЖИДАЕТ ПРИМЕНЕНИЯ ЧЕРЕЗ START**

Этот документ формируется после опроса. Каждое обязательное правило получает статус `ПРИНЯТО`, `ИЗМЕНЕНО ПОЛЬЗОВАТЕЛЕМ`, `НЕ ПРИМЕНЯЕТСЯ` или `ТРЕБУЕТ РЕШЕНИЯ`. Инициализация не завершается, пока остаются обязательные нерешённые правила.

## Реестр правил

| ID | Правило | Рекомендуемое значение | Текущий статус |
|---|---|---|---|
| CORE-01 | Файлы проекта — долговременная память | Включено | Требует решения |
| CORE-02 | `STATUS.md` — актуальный снимок | Включено | Требует решения |
| AI-01 | Агент читает правила и статус до работы | Включено | Требует решения |
| AI-02 | Опасные внешние действия требуют разрешения | Включено | Требует решения |
| DOC-01 | Session log создаётся при закрытии содержательной сессии | Стандартный | Требует решения |
| DOC-02 | Changelog не дублирует Git | Только пользовательские изменения | Требует решения |
| GIT-01 | Один приватный репозиторий на проект | Включено | Требует решения |
| GIT-02 | Сохраняются все неигнорируемые файлы | Включено | Требует решения |
| GIT-03 | Force push и переписывание истории запрещены без разрешения | Включено | Требует решения |
| SEC-01 | Секреты исключаются и проверяются по содержимому | Включено | Требует решения |
| SIZE-01 | Крупный файл требует решения пользователя | От 50 MiB | Требует решения |
| SESSION-01 | `закрываем сессию` разрешает commit и push | Только согласованный приватный origin | Требует решения |
| RECOVERY-01 | Новый агент сначала реконструирует контекст | Включено | Требует решения |
| REPORT-01 | Закрытие заканчивается проверяемым отчётом | Стандартный | Требует решения |

## Проектные исключения и изменения

Заполняются при `START`. Каждое изменение должно содержать причину и последствия.
