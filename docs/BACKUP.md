# Резервирование проекта

## Что сохраняет GitHub

Приватный GitHub сохраняет все файлы, которые были добавлены, закоммичены и отправлены. По принятой политике это все файлы проекта, кроме секретов из `.gitignore` и файлов, для которых пользователь выбрал другое хранение.

Git не сохраняет полностью пустые папки, поэтому они содержат поясняющие `README.md`. Служебная `.git` не является обычным tracked-файлом, но история commit передаётся через push.

## Что не сохраняется автоматически

- Секреты из `.gitignore`.
- Незакоммиченные изменения.
- Неотправленные commits.
- Файл, который пользователь решил хранить отдельно.
- Материалы за пределами корня проекта.

## Контроль полноты

При закрытии сессии агент должен проверить:

- нет ли неигнорируемых untracked-файлов;
- создан ли commit;
- отправлен ли commit;
- совпадает ли согласованный remote;
- остаются ли только известные ignored-секреты;
- есть ли нерешённые крупные файлы.

## Секреты

Секреты резервируются отдельно в защищённом хранилище пользователя. `docs/SECRETS.md` содержит только карту восстановления. Потеря отдельного хранилища секретов может сделать восстановленный проект неработоспособным, поэтому этот пункт проверяется при `START`.

## Дополнительная независимая копия

Второе хранилище можно подключить по решению пользователя. Оно не включается автоматически и описывается здесь после настройки.

## Проверка восстановления

После первичной настройки и крупных изменений структуры рекомендуется провести тестовый clone в отдельную папку, восстановить секреты безопасным способом и выполнить проверки из `PROJECT_CONTEXT.md`.

Последняя успешная проверка восстановления: не проводилась.
