# Как участвовать

Спасибо за интерес к AI Project Starter Kit! Принимаются исправления, улучшения формулировок, новые сценарии и доработки сайта.

## Прежде чем начать

- Ошибка или идея — создайте [issue](https://github.com/webuzateam/Starter-kit/issues/new/choose). Для крупных изменений сначала обсудите идею в issue.
- Уязвимость или утечка данных — **не** создавайте публичный issue, следуйте [SECURITY.md](SECURITY.md).
- Правила для AI-агентов, работающих с репозиторием, — [AGENTS.md](AGENTS.md). Людям они тоже полезны: там описано, где какое правило живёт.

## Структура

- `template/` — сам Starter Kit. Изменения здесь получают все пользователи.
- `site/` — сайт (Next.js). Требуется Node.js 22.13+.
- `scripts/` — проверки. `dev-docs/` — решения и процесс релиза.

## Процесс

1. Сделайте fork и ветку от `main`.
2. Внесите изменения. Одно правило — одно место: не дублируйте формулировки в нескольких файлах.
3. Если изменился путь, файл или команда шаблона, обновите `site/content/`, `template/README.md` и `template/docs/HOW_IT_WORKS.md`.
4. Добавьте запись в раздел `[Unreleased]` файла `CHANGELOG.md`, если изменение заметно пользователям.
5. Запустите проверки:

   ```bash
   node scripts/check-consistency.mjs
   bash scripts/test-preflight.sh
   cd site && npm ci && npm run check
   ```

6. Откройте pull request и заполните шаблон.

## Стиль текстов шаблона

- Пишите для человека без технического опыта: короткие предложения, без жаргона там, где можно обойтись.
- Императив для инструкций агенту («Прочитай», «Остановись»).
- Не ослабляйте защитные правила без решения в `dev-docs/decisions/`.

## Лицензия

Отправляя изменения, вы соглашаетесь распространять их на условиях [MIT](LICENSE).
