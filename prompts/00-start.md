# Команда START

Этот сценарий запускается только отдельным сообщением `START`.

## 1. Определи состояние

Прочитай `README.md`, `AGENTS.md`, `docs/PROJECT_QUESTIONNAIRE.md` и `docs/STATUS.md`. Проверь фактический корень, наличие лишней вложенной папки и существующего Git-репозитория. На этом этапе ничего не изменяй.

Если настройка завершена, не запускай опрос повторно. Кратко сообщи цель, статус, последний шаг и предложи начать рабочую сессию. Для пересмотра правил предложи команду `ИЗМЕНИТЬ ПРАВИЛА ПРОЕКТА`.

## 2. Покажи краткий отчёт starter kit

Объясни простым языком:

- зачем система хранит память в файлах;
- роль `README.md`, `AGENTS.md`, `PROJECT_CONTEXT.md`, `PROJECT_POLICY.md`, `STATUS.md`, `decisions/`, `sessions/`, `prompts/`, `src/` и `outputs/`;
- последовательность `START → опрос → ПРИМЕНИТЬ → аудит → Git → работа → закрываем сессию`;
- что Git сохраняет всё, кроме секретов;
- что решение по крупному файлу принимает пользователь;
- что до завершения опроса обычная работа не начинается.

Отчёт должен быть коротким и понятным, без копирования всего `README.md`.

## 3. Проведи опрос

Следуй `prompts/01-initialize-project.md`. Задавай вопросы блоками по 3–5. После каждого блока перескажи ответы, запроси короткое подтверждение и только затем запиши безопасную сводку в `docs/PROJECT_QUESTIONNAIRE.md`.

Не запрашивай значения секретов. Позволяй принять рекомендуемые настройки. Не выдумывай название, цель, владельца или фактическое состояние проекта.
