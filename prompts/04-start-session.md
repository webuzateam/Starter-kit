# Начало рабочей сессии

Начни новую сессию только после завершённой инициализации.

Прочитай:

1. `AGENTS.md`.
2. `docs/PROJECT_POLICY.md`.
3. `docs/PROJECT_CONTEXT.md`.
4. `docs/INTEGRATIONS.md`, если задача зависит от расширений.
5. `docs/STATUS.md`.
6. Актуальные решения.
7. Последний подходящий session log.
8. Git status, если Git настроен.

Ответь кратко:

- что это за проект;
- текущий этап и состояние;
- последний завершённый шаг;
- активные правила и ограничения;
- риски или блокеры;
- первый безопасный следующий шаг.

До получения задачи ничего не меняй.
