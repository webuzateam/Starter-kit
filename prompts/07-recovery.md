# Восстановление контекста

Я открываю проект после потери старого AI-чата, смены агента или нового clone.

Восстанови контекст только по локальным файлам:

1. `AGENTS.md`.
2. `docs/PROJECT_POLICY.md`.
3. `docs/PROJECT_CONTEXT.md`.
4. `docs/INTEGRATIONS.md`.
5. `docs/STATUS.md`.
6. `docs/decisions/`.
7. Последний подходящий session log.
8. `docs/GIT_POLICY.md` и `docs/RECOVERY.md`.

Проверь Git status, текущую ветку, последний commit и `origin`, если Git настроен.

Затем составь:

- карту проекта;
- цель и границы;
- последнее известное состояние;
- важные решения;
- уровень готовности, источники ключевых данных и отложенные решения;
- риски и блокеры;
- незавершённые задачи;
- состояние обязательных Skills, плагинов и MCP, включая отсутствующую авторизацию;
- первый безопасный следующий шаг.

Не считай отложенный вопрос ошибкой сам по себе. Проверь, что связанное действие явно заблокировано и что для вопроса указано событие повторного запроса.

Не редактируй файлы и не запускай внешние действия до завершения реконструкции.
