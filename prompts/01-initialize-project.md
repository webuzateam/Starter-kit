# Полная инициализация проекта

## Режим опроса

Используй все 13 блоков из `docs/PROJECT_QUESTIONNAIRE.md`. Пользователь должен выбрать или принять правила по каждому блоку. После первого подтверждённого блока установи статус `В ПРОЦЕССЕ`.

Для каждого правила фиксируй один статус:

- `ПРИНЯТО`;
- `ИЗМЕНЕНО ПОЛЬЗОВАТЕЛЕМ`;
- `НЕ ПРИМЕНЯЕТСЯ`;
- `ТРЕБУЕТ РЕШЕНИЯ`.

Обязательные правила не могут остаться нерешёнными. Если ответы противоречат друг другу, объясни противоречие и продолжи опрос только после решения.

## Перед применением

Когда все блоки пройдены:

1. Установи статус `ОЖИДАЕТ ПРИМЕНЕНИЯ`.
2. Покажи паспорт проекта.
3. Покажи все принятые и изменённые правила.
4. Покажи языковую политику, Git-политику, secret-пути, порог крупного файла, команды проверок и режим закрытия.
5. Перечисли файлы, которые будут заполнены.
6. Сообщи, что GitHub-репозиторий на этом этапе не создаётся.
7. Попроси отдельную команду `ПРИМЕНИТЬ`.

## После команды ПРИМЕНИТЬ

Команда действует только при полном опросе. После неё:

1. Заполни `docs/PROJECT_CONTEXT.md` без выдуманных фактов.
2. Сформируй `docs/PROJECT_POLICY.md` со статусами всех правил.
3. Обнови `docs/STATUS.md`.
4. Адаптируй проектные части `AGENTS.md`, не удаляя защитные правила.
5. Настрой `.gitignore` по подтверждённым secret-путям.
6. Обнови `.env.example` только именами переменных.
7. Заполни `docs/SECRETS.md` без значений.
8. Заполни `docs/GIT_POLICY.md`, `docs/BACKUP.md` и `docs/RECOVERY.md`.
9. Создай решение `docs/decisions/0001-правила-и-структура-проекта.md`.
10. Установи статус опроса `ЗАВЕРШЕНА`.
11. Запусти аудит из `prompts/02-audit-project.md`.
12. Сформируй `docs/INITIALIZATION_REPORT.md`.

## Финальный отчёт

Отчёт должен показать проект, корень, количество принятых/изменённых/неприменимых правил, отсутствие обязательных нерешённых правил, результаты аудита, активную Git-политику, режим секретов, крупные файлы, команду закрытия и следующий шаг.

Закончи одной из формулировок:

- `ПРОЕКТ ГОТОВ К РАБОТЕ`;
- `ПРОЕКТ НЕ ГОТОВ: ...` с конкретными нерешёнными пунктами.
