# Решения о Starter Kit

Решения о самом продукте: структура, политика, безопасность, развитие. Решения пользовательских проектов сюда не пишутся — для них есть `template/docs/decisions/`.

Формат — как в `template/docs/decisions/DECISION_TEMPLATE.md`. Номер не переиспользуется; изменённое решение заменяется новым со ссылкой.

## Индекс

- [`0001-task-protocol-and-project-observatory.md`](0001-task-protocol-and-project-observatory.md) — курс на `Task Protocol v1` и read-only Dashboard `Project Observatory`; реализация не начата.
- [`0002-public-open-source-release.md`](0002-public-open-source-release.md) — публичный релиз: лицензия MIT, монорепозиторий `template/` + `site/`, маркер мастер-шаблона, выбор видимости, `preflight.sh`.
