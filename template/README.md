# AI Project Starter Kit

Память AI-проекта в файлах, а не в чате. Любой AI-помощник — Claude Code, Codex, Cursor, Copilot, Gemini CLI — открывает папку, читает правила и текущее состояние и продолжает работу с того места, где вы остановились.

> English: copy these files into your project root, open it in your AI assistant and send `START`. The agent will answer in your language.

**Впервые здесь?** Простое объяснение без технических терминов — [docs/HOW_IT_WORKS.md](docs/HOW_IT_WORKS.md).

## Быстрый старт

1. Скопируйте содержимое этой папки прямо в корень проекта (без вложенной папки).
2. Откройте корень проекта в AI-помощнике.
3. Отправьте отдельное сообщение `START` и выберите режим: **с сопровождением**, **быстрый** или **без брифа**.
4. Проверьте итоговую сводку и отправьте `ПРИМЕНИТЬ`. Этот README будет заменён описанием вашего проекта.
5. Работайте. В конце — отдельное сообщение `закрываем сессию`.

## Команды

| Команда | Что делает |
|---|---|
| `START` | Первый запуск или краткий статус |
| `ПРИМЕНИТЬ` / `APPLY` | Записать сводку настройки в файлы |
| `закрываем сессию` / `CLOSE SESSION` | Обновить память, проверить, commit и push |
| `ВОССТАНОВИТЬ` / `RECOVER` | Восстановить контекст в новом чате или у нового агента |
| `ИЗМЕНИТЬ ПРАВИЛА ПРОЕКТА` / `CHANGE RULES` | Пересмотреть настройки |
| `ОБНОВИТЬ STARTER KIT` / `UPGRADE KIT` | Обновить Starter Kit без потери данных проекта |

В Claude Code те же команды доступны как `/kit-start`, `/kit-apply`, `/kit-close`, `/kit-recover`, `/kit-audit`, `/kit-upgrade`.

## Безопасность по умолчанию

- Удаление, публикация, deploy, смена remote или видимости, force push — только с вашего явного разрешения.
- Секреты не попадают в Git: `.gitignore` защищает по пути, `.starter-kit/preflight.sh` — по содержимому.
- Репозиторий проекта по умолчанию приватный; публичный — только по вашему выбору.
- AI не выдаёт догадки за факты: у каждого значимого значения указан источник.
